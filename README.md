# Agente de Prospecção Ativa B2B & Leads (`skill-prospeccao-ai-cowork`)

> Skill oficial distribuída pela **AI Cowork Academy** para empresários e gestores estruturarem **Prospecção & Captação** com Agentes de IA.

## O que este agente faz

Define perfil de cliente ideal (ICP), sinais de compra, critérios de qualificação e cadências de abordagem outbound.

## Como instalar em 1 comando

Copie e cole este prompt direto na sua IA (Claude Code, Codex, ChatGPT ou Antigravity):

```text
Acesse o repositório https://github.com/nitroxinteligence/skill-prospeccao-ai-cowork, leia o arquivo SKILL.md completo (e a pasta references/) e instale esta skill no meu workspace para eu usar agora.
```

## Como utilizar na prática

Informe o segmento das empresas que você quer atender e o ticket médio. O agente cria o mapa de ICP, critérios de qualificação e scripts iniciais de abordagem.
